## 新能力验证

- 稳定多帧自动触发，移动分布与低质量/空白信号不触发。
- 连续稳定信号至少四帧和 1.6 秒，单次完成不重复导航。
- 间歇信号不会绕过 12 秒超时；暂停/恢复与超时示例 UI 已实测。
- 实际 Vision 分析原创窗格图像：取得图像轮廓、重复证据；提取图与原始生成图不同，结果未偷偷换成标定图。
- 空白图像拒绝有效结构；新轮廓分析路径不生成 self similarity。
- 八种生活插画均确定性生成、坐标有效。螺旋与普通重复没有虚构嵌套子图或分形分数。
- 自动取景 → 冻结 → 轮廓揭示 → 证据页 → 路径回放 → 收藏走通。普通重复不开放生长 Alter。
- 生活图谱可进入螺旋研究，解释“螺旋不自动等于分形”，进入对应结果页。
- 新来源与证据字段保存/重启读取；不含 evidence 的旧 JSON 继续解码。
- 原植物发现、尺度对齐、规则改变、收藏恢复和原十种规则模型继续通过测试。

UI 验证修复了首次进入时的前台观察任务启动问题；任务现在以 scenePhase 为生命周期键，回前台重新积累稳定证据。相机权限请求期间的启动竞争也已在代码中处理，并经真机目标编译。

## 范围与未实测项

当前相机可对广泛画面提取轮廓和转折点，发现近似形状重复；植物上下文可尝试前景骨架。不代表通用分形分类准确率经过评测。河流、闪电和螺旋的专业自动分类尚未实现；它们提供明确标注的原创插画研究。

未实测：实体 iPhone 摄像头、首次允许/拒绝权限的完整系统弹窗、对焦、真实复杂背景、功耗、热量、实际 60 fps 与触觉。无障碍具备控件标签及 Reduce Motion 路径，但未进行完整 VoiceOver 人工审计。

录屏来自实际模拟器状态与数据，展示 **Guided camera preview**，没有合成替换 UI，也不作为实机摄像头能力证明。无视频上传、电影文件保存或麦克风采集。
